Password Strength Checker

Project Overview

The Password Strength Checker is a basic cybersecurity project developed using C++. It checks the strength of a password based on its length and character combinations.

Objectives

- Check password length.
- Identify uppercase and lowercase letters.
- Identify numbers and special characters.
- Classify passwords as Weak, Medium or Strong.

Technologies Used

- Programming Language: C++
- Compiler: GCC / Code::Blocks
- Concepts: Loops, Conditional Statements, Strings and Functions.

Working

1. User enters a sample password.
2. The program analyses its characteristics.
3. It calculates a strength score.
4. It displays the password strength.
